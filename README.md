Build own addons for NextGuide. You can fork this repository, make own addon and submit issue at [https://github.com/m1nsook/NextGuide/issues/new/choose](https://github.com/m1nsook/NextGuide/issues/new?template=submit-your-addon.md)
Verified addons will be added to NextGuide's Account mode under /marketplace where users can install your addon.
